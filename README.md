# Infra Systems

Live site: https://xio-shark.github.io/infra-systems/

A static course site for three courses:

- **INFRA 01 · Distributed Systems** — 21 lectures, 5 Go labs, based on the MIT 6.5840 schedule.
- **INFRA 02 · Cloud-Native Systems** — 14 lectures, 5 Linux labs on containers, images, networking, and multi-container systems.
- **INFRA 03 · Agent OS** — 12 lectures, 5 labs and a capstone on kernel-level atomic operations for agents. This is exploratory material, not a mainstream consensus.

The site is generated with Pandoc from `content/*.md` and served as plain HTML. It has no backend and no build-time JavaScript framework.

## Build

```bash
./build.sh
```

Output is in `dist/`. Open `dist/index.html` or serve it locally:

```bash
python3 -m http.server 8000 -d dist
```

## GitHub Pages

The repository includes `.github/workflows/pages.yml`, which builds the site with Pandoc and deploys `dist/` to GitHub Pages.

1. Create a repository (public, unless your plan supports Pages from private repos).
2. Push this directory as the repository root.
3. In **Settings → Pages**, set **Source** to **GitHub Actions**.
4. Push to `main` or run the workflow manually.

The site uses relative links, so it works under `https://<user>.github.io/<repo>/` without a custom domain. `dist/.nojekyll` is generated by `build.sh`.

The template currently sets `noindex, nofollow`. If you want the course to be searchable, remove that meta tag from `template.html`.

## Structure

```text
content/          Markdown sources
  index.md        course home
  course-map.md   INFRA 01 course page
  cloud-native.md INFRA 02 course page + notes
  agent-os.md     INFRA 03 course page + notes
  lectures.md     INFRA 01 lecture notes
  labs.md         all assignments
  papers.md       readings
  glossary.md     glossary
  setup.md        Linux/WSL2 environment
  rules.md        policies
assets/           style.css, app.js
template.html     Pandoc template
build.sh          build script
dist/             generated site
```

## Constraints

- All core labs run on one Linux or WSL2 machine: 2 vCPU, 4 GB RAM, 20 GB disk. No GPU, KVM, or multi-node cluster.
- The site does not include lab code or answers.
- INFRA 01 follows the MIT 6.5840 collaboration policy; its lecture notes are original Chinese summaries, not translations.
- INFRA 02/03 are original course material; readings are linked to public papers, specs, and documentation.
- INFRA 03 is explicitly exploratory: it proposes hypotheses and asks readers to argue for or against them, rather than presenting a standard.
